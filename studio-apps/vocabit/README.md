# Vocabit

[Quiz öffnen](https://larajacqueline-volkmer.github.io/studio-apps/vocabit/)

Tippe die deutsche Übersetzung des englischen Begriffs ein. Ein Hinweis zeigt Anfangsbuchstaben und Wortlänge. Jede richtige Antwort gibt Erfahrungspunkte. Über „Wörter“ ergänzt du eigene Paare. Wörter und Lernstatistik bleiben im Browser gespeichert.

Grundlage ist die gespeicherte Fassung vocabit-complete. Die Studio-Ausgabe ergänzt ein Installationssymbol, trennt ihren Offline-Cache und zählt jede richtige Antwort pro Runde einmal.
