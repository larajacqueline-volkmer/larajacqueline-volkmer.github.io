# Flow Focus Timer by LJV

[Timer öffnen](https://larajacqueline-volkmer.github.io/studio-apps/focus-timer/)

Wähle eine Dauer von 1 bis 180 Minuten. Start, Pause und Reset funktionieren per Touch und Tastatur. Die Restzeit wird aus der Zieluhrzeit berechnet. Einstellungen und abgeschlossene Sitzungen werden lokal gespeichert. Beim Neuladen beginnt der Timer wieder im Bereitschaftszustand.

Die App nutzt Design und Implementierung der Hostready-Fassung. Für die Studio-Ausgabe wurden Start/Pause, Bildschirmleser-Ausgabe und der Offline-Cache angepasst.
