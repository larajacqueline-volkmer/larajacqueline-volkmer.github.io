# Portal Run

Lara durch das Portal steuern und fallenden Blöcken ausweichen.

[App öffnen](https://larajacqueline-volkmer.github.io/studio-apps/portal-run/) · [Portfolio](../)

![Vorschau von Portal Run](preview.webp)

## Bedienung

Spiel starten, links oder rechts steuern und Punkte sammeln.

## Herkunft

Portal Run Lara Mobile Game. Vier geprüfte HTML-Kopien sind bytegleich.

## Lokal ausführen

Den Ordner mit einem statischen HTTP-Server bereitstellen, etwa mit `python -m http.server 8000`. Nach dem ersten vollständigen Laden speichert der Service Worker die App für den Offline-Start.
